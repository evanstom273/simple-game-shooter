# Simple Game Shooter

The landing page for Simple Game Shooter, an arcade game in development. It is built with React, TypeScript, and Vite, with a Dexie/IndexedDB schema ready for local settings and run history. The installable PWA shell is cached for offline launches.

## Run it locally

```sh
npm install
npm run dev
```

`npm run build` type-checks the app and creates the production bundle in `dist/`. `npm run preview` serves the production bundle locally.

## Install

Use the large **Install the app** button in a supported browser. If the browser does not offer an install prompt, open its menu and choose **Install app** or **Add to Home Screen**. GitHub Pages deploys the production bundle on each push to `main`.
